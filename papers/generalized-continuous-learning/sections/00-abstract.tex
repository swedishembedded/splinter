\begin{abstract}
We describe one method by which a local 4B model learns from an executable environment, with no human-written training tasks
or labels, and is judged by a separate examiner on sealed exams it never sees; we apply it to two task families. The
environment is the only teacher: a Lua~5.1 interpreter labels the programs the model proposes, and Vim and hidden checks grade
the file edits the model makes. In the first family, retraining Qwen3-4B on a pool of interpreter-labelled programs that
doubles at each generation raises its share of a fresh sealed exam of 2040 items from 5.1\% to 13.2\% after four generations
(+8.2 points, 95\% interval [+5.1, +11.5]), and raises it by +3.3 points [+0.7, +7.1] on program families no exam had used. In the
second family, editing files with Vim, a 27B model authors practice tasks from Vim's user manual alone; an oracle admits a task
only if replaying its reference solution in the task image gives the expected bytes; authoring the outcome first (start and end
files, request written last) yields tasks whose verified trajectories transfer more than tasks written section by section. On
100 hand-written sealed exams, each of the four arms in the registered comparison beats the base (which passes none of its
attempts) and beats a
control trained on the same trajectories with shuffled requests (which also passes none); the outcome-first arm passes 42 of
1200 exam attempts (3.5\%) on a third of the records. Against the operational definition of continuous self-improvement
stated in the introduction, the Vim family has one examined generation: held-out gain and robustness to the control hold for
it; three generations, retention and an unattended restart are not shown.
\end{abstract}
