\begin{abstract}
We ask whether a language model fine-tuned on one author's writings decides, through tool
calls, as the author would on topics, combinations of circumstances and tools it was not
trained on. With a real author this cannot be measured cleanly: the model may have met the
author in pretraining, and the author's decision in a new case is a matter of interpretation.
We therefore build a controlled benchmark in which an author is a function of a seed: four of
six tenets, each read one of two opposed ways and held in a hidden order of priority, decide by
code what the author does in any situation. A small hosted language model writes first-person
essays in which the narrator decides invented cases as the beliefs dictate without stating the
beliefs; code and a reading by the same model gate the essays; the model reads the decisions
back out, code verifies its quotations, and the decisions become tool-call records for a LoRA
adapter on Qwen3-8B. Each author's 160-item examination withholds topics, combinations of facts
and options, and tool schemas, and is graded by comparing the option named in the call with
the code oracle's decision, with no judge model. For three synthetic authors the adapter
takes the author's decision on \AccATuned, \AccBTuned\ and \AccCTuned\ of the items, against
\AccABase, \AccBBase\ and \AccCBase\ for the base model (chance is one third), and it exceeds the
base model told the author's name or given the author's beliefs as stated principles (exact
paired sign tests, $p<10^{-10}$ for each author). The base model given the six essay
paragraphs most similar to the situation is a strong baseline (\AccARetrieval, \AccBRetrieval\
and \AccCRetrieval): the adapter exceeds it for two authors ($p=\PTunedRetrievalB$ and
$p=\PTunedRetrievalC$) but not significantly for the third (\OnlyFirstTunedRetrievalA\ against
\OnlySecondTunedRetrievalA\ items on which only one of the two is right, $p=\PTunedRetrievalA$).
Where two authors decide differently, each adapter takes its own author's decision more often
than the other's in all nine comparisons. Of the decisions read out of the essays,
\AuditDisagreeAll\ of \AuditKeptAll\ (\AuditDisagreeRateMin\% to \AuditDisagreeRateMax\% per
author) disagree with the oracle; training used them unfiltered. Each author's adapter was
trained once.
\end{abstract}
