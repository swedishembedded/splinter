\begin{abstract}
Can a language model fine-tuned on one author's writings decide, through tool calls, as that
author would in cases, topics and tool schemas it was not trained on? With a real author this
cannot be checked: the model may know the author from pretraining, and the author's decision in
a new case is a matter of interpretation. We build a controlled benchmark in which an author is
a function of a seed: four of six tenets, each read one of two opposed ways and held in a hidden
order of priority, decide by code what the author does in any situation. A small hosted
language model writes first-person essays in which a narrator decides invented cases as the
beliefs dictate; code and a reading by the same model gate the essays; the model reads the
decisions back out, code verifies its quotations, and the decisions become tool-call records
for a LoRA adapter on Qwen3-8B. Each author's 160-item examination withholds topics,
combinations of facts and options, and tool schemas, and is graded by comparing the option named
in the call with the oracle's decision, with no judge model. For three synthetic authors the
adapter takes the author's decision on \AccATuned, \AccBTuned\ and \AccCTuned\ of the items
(chance is one third; the unadapted model \AccABase, \AccBBase\ and \AccCBase), more often than
the same model told the author's name or given the author's beliefs as stated principles (exact
paired sign tests, $p<10^{-10}$ for each author). Against the model given the six essay
paragraphs most similar to the situation, the adapter is ahead for two authors and not
significantly for the third. One adapter was trained per author, and the essays were written
and read by the same model.
\end{abstract}

\section*{Use of language models}
Language models were used in two ways. A hosted language model wrote the essays that are this
study's data and read them back, as \cref{sec:corpus,sec:mining} describe; that is part of the
method. Language models also assisted in drafting the text and the analysis scripts of this
paper. The author checked the numbers against the recorded data, verified the citations, and
takes responsibility for the content.
