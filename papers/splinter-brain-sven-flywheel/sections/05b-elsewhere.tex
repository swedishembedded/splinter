\section{The same loop elsewhere: no gain shown}\label{sec:elsewhere}

The full loop (\cref{app:loop}) was also tested where it was built for. On repository tasks, an 8B
student trained on a 27B teacher's verified trajectories was not shown better than its base by the
registered confirmatory query: it solved 23.0 of 46 tasks on average over three seeds against 20.0, 18
families won and 12 lost ($p=0.18$); a same-seed contrast showed that supervising every action, rather
than only file edits, does harm (\cref{sec:coding-summary}).\cl{QUAL1} Two promoted generations of a
27B model trained on its own agent experience did not beat their base on one measurement
(\cref{sec:generations}).\cl{G2703,G2704} An exploratory, unregistered run in which a 4B model learned
from a raw manual gained on its own probes, with no detected effect of which model wrote its tasks
(\cref{sec:documentation}).\cl{SL23}
