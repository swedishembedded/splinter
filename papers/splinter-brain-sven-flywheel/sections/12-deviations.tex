\section{Deviations from the registration}\label{app:deviations}

The protocol of \cref{sec:protocol,sec:pending} is the registration as it stands. It was
fixed in \code{prereg/coding-tasks.md} before any coding-task run and changed only by dated
amendments appended to that file, each pushed before the outcome it could affect; the file is
never rewritten, so every row below can be checked against its git history.
\Cref{tab:deviations,tab:deviations2} list every change. ``No.'' is the amendment's number in that file; ``Before'' names the earliest outcome the change preceded.
