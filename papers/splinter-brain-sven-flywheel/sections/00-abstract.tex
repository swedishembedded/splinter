\begin{abstract}
A local model can keep learning from a team's documents, tools and repositories only if the
path from a source to a released model can be inspected stage by stage. We describe a
self-learning loop built from three cooperating projects, Splinter (what is learned), Brain
(training and serving) and Sven (agents): a model proposes tasks that code admits or refuses
for named reasons, an agent attempts them, typed verifiers keep what they confirm, verified
experience becomes training data for a LoRA adapter, and the result is released only if four
checks over unseen material pass, with immutable releases and rollback. We state the
requirements that make such a loop work (independent held-out units, a retention check that
tests what was acquired, an anchor bound that counts net lost answers on a large enough suite,
a verifier that proves the tests ran, canaries in the gate), tie each to the code that
implements it or mark it planned, and report what the training substrate of one 95~GiB card
holds for a 27B model (bf16 LoRA and NF4 QLoRA qualified; a probe step at
\mThrNfFourEightOneNineTwoTokensPerS{} tokens/s, as measured). Every statement about the system
or a measurement carries an id in a claims ledger and is re-checked against the three
repositories at pinned commits or against a raw run record. Finally we report the experiment the loop exists for, registered before any run: whether a small
model's adapter, trained on verified trajectories that a larger teacher produced, raises completion
of unseen repository tasks over the untrained small model. The registered confirmatory query does
\emph{not} show it: on 46 qualification families the candidate registered in advance reaches a mean
pass@1 of 23.0 against 20.0 for its base (18 families won, 12 lost, 16 tied; one-sided sign test
$p=0.18$). The same-seed contrast that changes only the supervision, decisive actions against all
actions, does separate (26 wins, 11 losses, 9 ties, $p=0.010$), as did the six-seed development
comparison of the candidate against its base ($p=0.040$).\cl{QUAL1,PROTO6} The larger model's training on
its own trajectories was stopped by its registered memorisation guard before any evaluation, a pilot
of its guarded variant showed no improvement, and the registered replication on a second repository
was not run. We then run the loop with no teacher at all: a 4B model reads raw HTML of a language
manual, writes its own tasks, has them checked by the language's interpreter, and is fully fine-tuned
each round. At a small learning rate each arm accepted 5 rounds, and on final probes no round trained
on the model went from 26 to 35 of 53 when it wrote every round's tasks itself and from 26 to 40 when
its untrained base wrote them; a second replicate on a fresh exam gave 20 to 30 and 20 to 29 of
46. The loop learns from tasks its own model writes; that the trained model's tasks help more than
its base's is not shown.\cl{SL20,SL21}
\end{abstract}
