\section{What the loop needs in order to work}\label{sec:requirements}

A turn of the loop adds a capability only if its stages cannot be satisfied by an artefact of
the setup. This section states the requirements we found necessary, the mechanism that
implements each, and which are not yet implemented. Each names its commit or file in the
ledger, which checks that the commit is in the history of the pinned revision of its
repository (\cref{sec:repro}).

\paragraph{Held-out units must be independent.} Records carry the group of the source text they
are grounded in, and a held-out measurement needs whole groups. A dataset that is one source
text cannot be divided, so the split refuses it with a typed error naming the cause instead of
dividing the group and failing the leakage check afterwards; a free record follows the fixed
side of its group, monitoring with no whole group to set aside is skipped with the reason
recorded, and a source that is one independent text is refused at intake before any rollout is
paid for.\cl{FX01,FX05} A source of independent units is therefore one file per unit.

\paragraph{Admission must see through markup.} The subject of a task is compared with the
instruction, the source and the variants through one function that ignores code quotes,
quotation marks, emphasis and a call's empty parentheses, so that ``the \code{q} key'' contains
the subject ``q key''.\cl{FX02} A number written with a thousands separator is the same number
in the stated-reference check.\cl{FX06}

\paragraph{The serve check must start the real server.} The gate's serve check runs
\code{brain serve --adapter}. A candidate's card id must follow Brain's adapter grammar
(base, owner, name, tag), and the check must pass the bank option that covers every linear
Splinter's LoRA corrects; the test double of the server refuses an adapter offered without it,
because a double that accepts any flags hides both.\cl{FX03,FX04}

\paragraph{The anchor bound must count net lost answers on a large enough suite.} A rate bound of
0.02 on a 40-question anchor suite allows no lost answer, since one net loss is 0.025. The gate
can decide the anchor on answers lost net of answers gained (an option; the default rate bound
is unchanged), and a 200-question anchor suite built by code and a reviewed list
exists.\cl{FX07}

\paragraph{Retention must test acquired capabilities.} The retention suite of each earlier
release is built from that release's held-out split, and the exams of workspace families are
added to it.\cl{OP01} For a domain of facts the held-out split holds facts the release never
taught, so a passed retention check is not evidence that taught facts were kept. A retention
exam drawn from what each release demonstrably acquired is planned and not implemented; the
registered coding-task retention check (\cref{sec:protocol}) uses the exam families of every
earlier round for this reason.

\paragraph{The verifier must prove that the tests ran.} The workspace verifier passes a patch
only if every fail-to-pass and pass-to-pass command exits with status 0.\cl{OP02} That does not
prove that the intended tests ran, so a suite that exits zero without running them would pass.
At the current head a command that carries a test expectation passes only when the runner's own
report shows every expected test run and passed, with readers for \code{python3 -m unittest} and
\code{cargo test}; a command without an expectation is still judged by its exit status.\cl{OP05} The
coding-task experiments register conformance measurements for the verifier before they count
(\cref{sec:protocol}).

\paragraph{The gate must carry canaries.} A gate with an empty canary set skips that check. At the
revision the paper's architecture claims are pinned to, the release gate called from \code{practice}
was built without canary tasks;\cl{OP03} at the current head it is handed up to 20 canaries made from
the exam the run reserved, so a release from \code{practice} carries that evidence.\cl{OP04}

\subsection{Trajectory and training requirements of repository tasks}\label{sec:audit}

Training an agent on its own repository trajectories adds requirements to the stack. Each is
located in source; the ledger names the file, commit or test.

\begin{enumerate}
\item \textbf{Loss masking of tool conversations} (Brain; implemented). Under the Qwen3 template
an empty reasoning block is added to the last assistant turn only, so non-final assistant
turns of a multi-step conversation failed the trainer's boundary check. Tool-calling
conversations now train per assistant turn in both thinking modes.\cl{AU01}
\item \textbf{Tool definitions lost between recording and training} (implemented). The agent
records the tool definitions of the run, but the trajectory projections dropped them; an
ATIF trajectory's tool definitions now become the chat sample's tools, and Splinter's
dataset check covers tools.\cl{AU02}
\item \textbf{Trajectory fidelity in the agent SDK} (Sven; implemented). The exported trajectory
marked no context compaction and kept the uncompacted history, listed every registered tool
rather than those offered, and turned unparseable tool-call arguments into an empty object.
Compactions are now marked and the compacted history kept, the offered tools are exported,
and the raw text of non-JSON arguments is kept.\cl{AU03}
\item \textbf{The record is the whole conversation} (Sven; implemented). After a context
compaction the export was rebuilt from the compacted history, so a run that compacted lost the
steps the compaction replaced and the model requests recorded on them. In the withdrawn 27B run
the five episodes stopped at the 60-call cap counted 61 or 62 tool calls while their trajectories
held four to 42. The agent now keeps an append-only record beside the history the model reads, a
child run's store keeps a transcript the same way, and a compaction is marked where it fired. The
projection into training conversations still refuses a trajectory that holds a compaction marker,
so such episodes can be analysed and are not trained on.\cl{TJ03,TJ04}
\item \textbf{Sampling identity on every request} (Sven and Brain; implemented). A run's
sampling (temperature, top-$p$, top-$k$, seed) and its request for the sampled tokens reach every
model request of the run and of the children it starts. Brain's chat endpoint returns the prompt
token ids, the sampled token ids, the log-probability of each sampled token under the
distribution it was decoded from, and the seed it used, the adapter, the base-checkpoint digest, the
backend and the engine build; a step of the trajectory records them, and records each request's
own prompt and tokens when a step covers several. A seed the server drew above $2^{63}$ was once
dropped from the reply and refused when sent back.\cl{TJ05,TJ06,TJ07}
\item \textbf{Crash-robust capture} (Sven; implemented). The trajectory can be written one
record at a time as the run happens, with a flush policy and size bounds; a journal that was never
closed reads back marked incomplete, a test kills a real second process inside a model request
and reads the journal back, and Splinter's projection refuses a trajectory marked incomplete.\cl{TJ08,TJ09}
\item \textbf{Children in the parent's record} (Sven; implemented). A harness run's trajectory
embeds every finished child as a trajectory with its tool actions and the account of each of
its model requests, sampling identity included.\cl{TJ10}
\item \textbf{Release probes were closed-book} (implemented). A coding agent is now gated on the
exam its run reserved, with report types for workspace suites.\cl{AU04}
\item \textbf{Contamination paths} (implemented). The semantic-memory tool is withheld from the
worker, and a context tool that could open any readable path is jailed.\cl{AU05}
\item \textbf{Silent waits} (Sven; implemented). A model server that goes quiet is bounded and
the wait is reported, with a stalling mock provider to test it.\cl{AU06}
\item \textbf{Tool-definition mismatches} (Sven; implemented). Definitions disagreed with the
implementation and were tightened.\cl{AU07}
\item \textbf{Serving several adapters} (Brain; implemented in the qwen3 server). An adapter bank
lets one batch serve the base and many LoRA adapters.\cl{AU08}
\item \textbf{Containment} (implemented for commands run on the host; a container remains
the stronger option). A solver's forbidden operations are prevented by the kernel, not
detected afterwards by the exposure audit. A command of the solver (its shell, and the
checks, and a code call of the \code{run_code} tool\cl{CN13}) runs under Landlock with read access to the system and write access to its own tree
and a private directory only, so the withheld tests,\cl{CN01} a path traversal or a symlink
out of the tree,\cl{CN02} the host's credential files,\cl{CN03} and a sibling candidate's
tree\cl{CN06} are refused with a permission error, also when reached through \code{sh -c}, an
interpreter or a compiled helper the candidate brought along.\cl{CN07} The command's
environment is built from an allowlist from which names that look like secrets are dropped even
when the allowlist names them;\cl{CN04} Landlock's ptrace check already refuses the files of another process's
\code{/proc} directory that need ptrace access (its environment among them),\cl{CN05} and the command
runs in a private user and pid namespace with a \code{/proc} of its own, in which no other process
of the host exists at all;\cl{CN14} the network is denied (Landlock's
TCP rules and a socket filter that also covers UDP), so a command cannot reach a model server on the
loopback;\cl{CN08} and a process budget stops a fork bomb when the operator sets one.\cl{CN09} A kernel
without Landlock ABI~4 refuses to run the command rather than run it open. The agent's own file
and search tools are confined to the attempt's tree by the agent framework's project root,
which its delegated children share.\cl{CN10} Only an experience that an independent verdict
passed at executable strength is training evidence.\cl{CN11} The step-level view of the
training data also admits an action a labeller marked good from an experience nobody verified;
that is the default, \code{--control outcome-verified} turns it off, and the dataset manifest
records which was used.\cl{CN15} A path outside the tree that a command names is reported by what came of it (the sandbox refused it, it did not exist, or something came back), so the audit separates a harmless mention from an access; all three still fail it.\cl{CN12} Not covered: the process budget and network opt-ins change the
environment record, so they are off or unset by default to keep the identity of tasks generated
earlier, and a kernel that cannot create a user namespace refuses to run a command unless the
operator allows the host's \code{/proc}.
\end{enumerate}

\subsection{After the first generation: teaching, acquiring, choosing, retaining}\label{sec:after}

Four further requirements follow from asking the loop to run past one repository and one
round. Each is a property of the stack, shown by a specification that runs on scripted agents
and a test double of the trainer; none is a measurement of a trained model. The experiments
that would be are registered in \code{prereg/acquisition.md} (ACQ1, INT1, GEN1)\cl{PL03} and were
not run (\cref{sec:limitations}).

\paragraph{A task nobody solves needs a teacher that is not trusted.} A repository task has no
passage to show a teacher, so \code{practice} used to drop every task the policy never solved:
the frontier keeps only what is solved sometimes. A teacher is now named for those tasks. It is
either the task's own reference change (the inverse of the seeded fault, which the task keeps
and the student is never shown) replayed as the actions of an agent through sven's tools, or a
stronger model solving the task as an agent. Either produces an experience that is graded by the
same workspace verifier and the same exposure audit as the policy's attempts: a demonstration
that does not make the hidden checks pass is not kept, whoever proposed it.\cl{TC01,TC02,TC03} A
replayed demonstration names the file without searching for it, so it teaches the edit once the
place is known and not the localisation; that is a stated limit.\cl{TC04}

\paragraph{The probes must exist before the training and decide nothing in it.} A run that
turns documentation into skills measures each skill on probes written from the skill's own
sections and checked to exercise it. The probes are split: the dev half measures the baseline,
each round's gain and what a round cost the skills measured before, and the final half is
touched only by the closing assessment, which compares the policy the run began with and the one
it ends with. No training task repeats a probe, and no teacher answers one.\cl{AQ01,AQ02} A
candidate that learns nothing is rejected, counted against its skill, and leaves the policy as it
was.\cl{AQ03} What a planner model proposes is kept only as far as the text bears it out: a quote
that is not in a section the skill cites, a symbol that is not in them, a prerequisite that is
no skill or closes a cycle are refused with the reason.\cl{AQ04}

\paragraph{An intervention is chosen by what it was measured to do, net of what it costs.} The
choice among more samples, another episode protocol, a trained candidate and no change rests on
the lower confidence bound of the paired gain over families, priced against what a success is
worth, and a mechanism that is not available is reported as not measured, never as a gain of
zero.\cl{IV02} On four synthetic clusters whose outcomes are drawn from a known world, the choice
differs by cluster and its realised value exceeds every strategy that applies one intervention to
all four.\cl{IV01}

\paragraph{Retention is measured on every generation, not inferred.} A generation of the coding
policy measures the champion on every protected task before it trains and the candidate and the
champion on the same tasks at the same settings; the full matrix has the base as generation 0 and
every generation on every protected task, so backward and forward transfer have measured
cells.\cl{GN01,GN02} A candidate that loses a protected family beyond a limit, or does not gain
on the new exam, is rejected before the gate is asked, the alias stays, and the rejection is
recorded with the numbers it rested on.\cl{GN03} Replay is a policy rather than a constant: none,
uniform, balanced over capabilities, weighted by the champion's failures, or a rebuild from the
base on everything accumulated.\cl{GN04}

\paragraph{A language's version is part of the environment.} The Lua families and the \code{lua}
runtime ran on whatever \code{lua} the host's alternatives named. The runtime now refuses an
interpreter whose version line is not Lua 5.1, and the interpreter is built from its checksummed
release tarball.\cl{LU01}
