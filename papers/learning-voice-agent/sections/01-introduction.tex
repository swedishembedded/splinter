\section{Introduction}\label{sec:intro}

\paragraph{Question.}
When a person works with an agent by voice, what do they correct? Rarely how a word is pronounced. Far more often: ``that deadline is
Monday, not Friday'', ``never push to main without asking me'', ``here is how we deploy''. Can an agent keep such corrections, apply them
the next time they bear on what it does, replace what they correct, and give them up when told, without the user having to repeat
themselves and without anything else getting worse? And can the same machinery carry the smaller class of corrections about how the
agent speaks? This paper formalises the setting, reports the experiments that exist, states the pre-registered gates they were held
to, and lists what failed. A finding belongs here if it changes what is claimed about an agent that turns spoken or typed
feedback into stored, applied, reversible knowledge of facts, rules, procedures and manner of speech.

\paragraph{Contributions.}
(i) A typed account of what a user teaches (\cref{sec:teachings}): fact, rule and procedure, with a conservative reader, a model-assisted
reader that is checked as carefully as the user's words, and a ledger with supersession and retraction.
(ii) A confirmation protocol: the agent restates, the user says yes, and only then is it kept (\cref{sec:system}).
(iii) A pre-registered evaluation on facts no model can know, with an untaught arm and a new-session arm
(\cref{sec:evaluation,sec:results}).
(iv) The earlier layer for how the agent speaks: pronunciation, imitation and preference lessons, and a group-relative optimiser over the
synthesizer with its baselines, tested so far on a planted reward only.

\paragraph{What is not claimed.}
Every voice in this work is a synthetic theatrical portrayal; no recording of Samuel Adams or Thomas
Jefferson exists, so no voice here is theirs, and every report and spoken session carries that label.
Until a real-speech test set is recorded and measured, nothing is claimed about real human speech.
``Trained persona'' is not claimed: the persona is a language model under a system prompt (\cref{sec:system}).
