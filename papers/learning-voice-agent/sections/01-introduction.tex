\section{Introduction}\label{sec:intro}

When a person works with an agent by voice, what do they correct? Often not how a word is pronounced, but what the agent said or did: ``that deadline is
Monday, not Friday'', ``never push to main without asking me'', ``here is how we deploy''. Can an agent keep such corrections, apply them
the next time they bear on what it does, replace what they correct, and give them up when told, without the user repeating themselves and
without anything else getting worse? And can the same machinery carry the smaller class of corrections about how the agent speaks?

\paragraph{Contributions.}
(i) A typed account of what a user teaches---a fact, a rule or a procedure---with a conservative reader, a model-assisted reader whose output is validated before it can become a teaching, and a ledger with supersession and retraction (\cref{sec:teachings}).
(ii) A confirmation protocol: the agent restates what it understood, the user says yes, and only then is it kept; when a teaching is taken back the conversation starts over, because the model's own replies would keep it alive (\cref{sec:system}).
(iii) A pre-registered evaluation on facts no model can know, with an untaught arm and a new-session arm, that reports what passed its gate and what did not
(\cref{sec:evaluation,sec:results}).
(iv) The layer for how the agent speaks (pronunciation, imitation, preference), a group-relative optimiser over the synthesizer shown to learn a planted
reward against two baselines, and a spoken agent whose first sound is measured (\cref{sec:formalism,sec:results}).

\paragraph{What is not claimed.}
Every voice in this work is a synthetic theatrical portrayal; no recording of Samuel Adams or Thomas Jefferson exists, so no voice here is theirs, and every
report and spoken session carries that label. Nothing is claimed about real human speech or about how users phrase corrections: the utterances are written by us
(\cref{sec:discussion}). ``Trained persona'' is not claimed: the persona is a language model under a system prompt (\cref{sec:system}).
