# Capability inventory and discrepancy report (package P0-INV), 2026-10-16

Scope: the crates, CLI verbs and SDK entries of splinter, sven and brain that the target
pipeline (master plan v2, phases 1-4: real-task benchmark, retention and anchors, failure
taxonomy, training contract) could touch. Sven and brain were read, never changed.

Heads read: splinter `38dbb2b` (this worktree's base), sven `5d08cbea`, brain `465448ae`
(all equal to their `origin/main` after a fetch). **Splinter does not build against these
heads**: `Cargo.lock` pins sven at `02adbda7` (18 commits behind) and brain at `dc50b7cc`
(129 commits behind); see D24.

Classes: (a) historical defect, already fixed; (b) currently reproducible defect; (c)
evaluation or architectural flaw that remains when the code behaves as written.

## 1. Method

### 1.1 Columns

* **Interface**: where the public entry is declared (`file:line`).
* **Implementation**: size of the code behind it (lines of Rust under `src/`).
* **Tests**: number of `#[test]`/`#[tokio::test]` attributes under the crate, with the first
  one's `file:line`. A count is not coverage.
* **Consumers**: who depends on it, from the search commands in 1.2. "Linked" means it is in
  splinter's compile closure (`S4`), which is not the same as used.
* **Phase 1-4**: whether the target path (phases 1-4 of the master plan) calls it.
* **Validation**: the strongest run evidence at the heads (section 5), otherwise the test
  type.
* **Cost**: dominant resource.
* **Overlap**: another implementation of the same thing, if one was found.
* **Rec.**: retain, repair, merge, isolate, or delete (a candidate, never an action).

### 1.2 Consumer search commands (every row cites one of these)

Run from the directory holding the three checkouts (`code/`) and the splinter worktree.

* **S1 (Cargo dependents)**: for crate `<name>`, every `Cargo.toml` under the three repos
  (excluding `target/`, `.git/`) that has a line matching `^\s*<name>\s*[={.]`, excluding the
  crate's own manifest. Generated by a script over all manifests; the column shows
  `repo:count (first three dependents)`.
* **S2 (CLI verb use)**: `grep -rIlE "splinter +([-a-z]+ +)*<verb>\b" scripts papers Makefile samples`
  in the splinter worktree. A verb with no hit here is used only by tests and the REPL, not by
  any script, paper or sample.
* **S3 (source reference)**: `grep -rIl "<crate_name_with_underscores>\b" sven brain <splinter>
  --include=*.rs --include=*.toml --include=Makefile --include=*.sh --include=*.py`
  excluding the crate's own directory. Run for every crate with zero S1 hits.
* **S4 (compile closure)**: `cargo tree -p splinter --offline -e normal --prefix none` in the
  splinter worktree, filtered to `sven*`, `brain*` and `atif`: 120 crates, of which 84 are
  brain and 36 are sven.
* **S5 (cross-repo names)**: `grep -rIl splinter sven brain` finds only
  `scripts/gates/check-repo-scope.sh` in each: neither sven nor brain refers to splinter.
