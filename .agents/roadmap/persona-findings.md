# Persona program: findings ledger

Defects and risks found by reading the persona pipeline end to end (synthetic
author, persona chat, `learn`, the model adapter, the paper's data) and, where
the code alone could not settle a question, by recounting the study's own
corpus and examination directories (kept outside the repository; the counts
below are reproducible from `decisions.jsonl`, `rejected.jsonl`, `articles/`,
`exam/<arm>.jsonl` and the outputs of `synthetic-author plan` and `items`).
Each finding names the work item that removes it (see
`persona-program.md` for the index). A finding whose item is done keeps its
text as found; its evidence names the code by file and function, because the
lines it pointed to no longer hold the defect.

Status: **confirmed** means the defect was shown by the code and, where a
number is given, by a recount; **unconfirmed** means a suspicion with what
would confirm it. A check that came back clean is listed at the end so it is
not repeated.

## Checked and clean

- Grading by string comparison: every one of the 2,400 first answers in the
  study's exam files names a label of its item exactly; none was lost to
  case, spacing or punctuation (`samples/synthetic-author/src/tools.rs:134-144`, `Schema::read`).
- Retrieval arm leakage: exam case names are disjoint from the corpus plan's
  (`src/exam.rs`, `items`), and no article is written on a withheld topic
  (`src/writer.rs`, `TRAIN_TOPICS`, `HELD_OUT_TOPICS`, `plan`), so the retrieved paragraphs cannot hold an
  exam case or a withheld topic.
- Withheld combinations in training: no planned episode is a withheld
  combination, and of the fixed-wording briefings whose mined facts differ
  from the plan (3, 3 and 0 per author) none states a withheld combination.
- Duplicate exam answers: only author 202's tuned file repeats ids (241 lines
  for 160 items); `read_unique` and `collect.py` take the first answer, and the
  repeats equal the first answers.
- Wilson interval and exact sign test arithmetic in
  `samples/synthetic-author/src/report.rs` (`rate`) and
  `papers/persona-training/scripts/build_data.py` (`wilson`) match their textbook
  forms; the Newcombe interval is applied to independent cells only.
- `plan` is prefix-stable: article `i` tells the same episodes whatever the
  planned count, so `show` (default 60 articles) and `exam` (default 100)
  agree on the articles both cover (`samples/synthetic-author/src/writer.rs`, `plan`).
- The Splinter test tree has no early return on a missing prerequisite.
